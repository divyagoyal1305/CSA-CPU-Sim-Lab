# CSA CPU Sim Lab

Implementation of Computer System Architecture (CSA) practicals using CPU Sim and Mano's Basic Computer architecture.

## Practicals

| Practical | Description | Status |
|---|---|---|
| 01 | Create a machine based on Basic Computer architecture | Machine file/screenshots pending |
| 02 | Implement the Fetch routine | Source/manual verification pending |
| 03 | ADD two user-entered numbers | Program prepared from lab context |
| 04 | SUBTRACT two user-entered numbers | Program prepared from lab context |
| 05 | Implement logical operations | Exact manual program verification pending |
| 06 | Implement memory-reference instructions | Program prepared from lab context |
| 07 | Register-reference instructions: CLA, CMA, CME, HLT | Exact manual program verification pending |
| 08 | Register-reference instructions: INC, SPA, SNA, SZE | Exact manual program verification pending |
| 09 | CIR and CIL | Exact manual program verification pending |
| 10 | Sum integers until a negative number is read | Program prepared from lab context |
| 11 | Sum integers until zero is read | Program prepared from lab context |

## Software

- CPU Sim 4.0.11
- Java

## Basic Computer Architecture

- 16-bit data
- 12-bit memory addresses
- 4096 memory locations
- Accumulator-based architecture
- Microprogrammed control

## Repository Structure

Each practical has its own directory. Assembly source is included where the exact program content is currently supported. Screenshot directories are represented by README placeholders until actual CPU Sim screenshots are available.

The machine directory is reserved for the real BasicComputer.cpu file. No fabricated CPU Sim machine file is included.

## Verification Note

Programs are not claimed to have been verified by running them in CPU Sim unless an actual CPU Sim run has been performed. The lab manual remains the source of truth for exact programs, procedures, terminology, and expected outputs.
